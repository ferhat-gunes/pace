# Interface skill selection

The owner requested a calmer, premium mobile interface and research into appropriate design skills. The installed skill catalog and official OpenAI curated catalog were inspected.

## Applied skills

- frontend-design: coherent identity, deliberate typography, restrained copy and visual structure.
- ui-ux-pro-max: local mobile interaction searches; target sizing,8px spacing, input types and responsive review. Generic landing-page/clay-style results were rejected because they did not fit the product or owner-approved direction.
- impeccable: Operate-mode restraint, component quality, responsive render review and contrast checks.
- webapp-testing, systematic-debugging and verification-before-completion: actual browser scenarios, event tracing, error investigation and evidence-led release checks.

The curated catalog also contains Figma and browser skills. This application already has a functioning source-based design and browser workflow; no new account connection or redundant installation was required. The work used the matching installed capabilities.

## Agent division

One agent rebuilt the stylesheet; another diagnosed interaction failures and maintained click/undo behavior; an independent agent compared previous and redesigned screens at phone and desktop dimensions. The primary agent owned the product direction, single-value minute entry, tests, font delivery and release.

## Resulting changes

Manrope is self-hosted with its SIL OFL license. The interface uses cool light surfaces, restrained orange actions, semantic SVGs and cohesive habit controls. Saved undo moved to an eight-second toast. A pointerdown/blur/click regression was diagnosed and fixed by retaining unchanged button descendants. Long units are truncated only in the repeated stepper label, while the full unit remains available in the goal caption.
