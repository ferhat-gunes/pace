# Contributing to PACE

Thanks for taking an interest in PACE. The project is still in its first implementation phase.

## Before opening a change

- Keep the Today screen direct and low-clutter.
- Preserve historical habit settings when a user changes a schedule or goal.
- Keep habit records private and scope every data operation to the authenticated account.
- Never commit API keys, email credentials, `.dev.vars`, `.env`, account exports, or personal habit data.
- Use short, plain Turkish interface copy and retain accessible labels and keyboard behavior.

## Proposing work

Open an issue with the user problem, the expected behavior, and any relevant edge case. For a code change, describe the affected screens or API routes and how you checked the result.

Please note that the repository license is still pending; the owner will add a license before accepting external code contributions.
